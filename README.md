## Overview:

Madoku Craft: Quests give you daily objectives to complete.
When completed, they reward you items and experience.
You can customize this feature in the config files.

## Dependencies:

- Fabric API
- Madoku Craft: Core

## Features:

**Quests**

- By default, the keybind to open up the main menu is Tab.
- This keybind is customizable in the in-game settings.
- The quests menu is located in the main menu.
- You can select which quest to track on the HUD.
- Once the requirements are met, you can turn in quest for rewards.
